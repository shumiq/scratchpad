# Table Pad: range selection

**Depends on:** 08-table-grid
**Done when:** a rectangle can be selected with the mouse, is clearly highlighted, and row/column selection is easy.

- [ ] Drag from one cell to another selects the rectangle.
- [ ] Clear visual highlight on selected cells.
- [ ] Clicking a row/column header selects the whole row or column.
- [ ] Escape / click outside clears the selection.
