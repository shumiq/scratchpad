# Image Pad: export PNG/JPG

**Depends on:** 15-image-transform
**Done when:** the current image downloads as `.png` and as `.jpg`.

- [ ] `toBlob` at full resolution, download via object URL, URL revoked after.
- [ ] Filename derived from the pasted file name or a timestamp.
- [ ] JPG export quality is a fixed sensible default, recorded in `wiki/image-pad.md`.
