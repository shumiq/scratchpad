# Table Pad: copy selection as text

**Depends on:** 11-table-selection
**Done when:** copying a selection pastes into Excel/Sheets as the same rectangle.

- [ ] Copy current selection, or the whole grid when nothing is selected.
- [ ] Cells joined with `\t`, rows with `\n`, no trailing delimiter.
- [ ] `Ctrl/Cmd+C` and a copy button both work while the grid has focus.
- [ ] Tabs/newlines inside a cell are handled (kept or escaped — pick one and document it).
