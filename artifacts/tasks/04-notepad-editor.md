# Notepad: editor with line numbers

**Depends on:** 03-page-frame
**Done when:** the gutter stays aligned with the text while typing, wrapping and scrolling.

- [ ] Full-height text area, monospace, starts focused so typing works on open.
- [ ] Gutter with one number per logical line.
- [ ] Numbers stay aligned when a long line wraps and when the text scrolls.
- [ ] Large paste (e.g. 5k lines) does not lock the UI.
