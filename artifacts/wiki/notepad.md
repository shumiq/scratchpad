# Notepad

Write plain text, with line numbers and a markdown preview.

## Behavior

- Full-height text area; typing starts immediately, no save button.
- Line numbers in a gutter, kept in sync with the text (including wrapped lines).
- Markdown preview panel next to the editor (side by side from 1024px up, one pane at a
  time below that), showing the same document rendered.
- On narrow screens a header toggle picks the editor or the preview, keeping the text and the caret.
- Autosaves as you type.
